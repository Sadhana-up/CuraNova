This multimodal, bidirectional system integrates specialized medical AI with real-time verification protocols. Built using the Google Agent Development Kit, it allows for seamless medical asset evaluation through a distributed multi-agent architecture.

System Overview
The system acts as a medical assistant agent capable of evaluating images, X-rays, and prescriptions. It leverages a three-tier architecture: Interaction (Gemini Live), Reasoning (MedGemma), and Verification (Search Agent).

Architecture & Protocols
1. Main Orchestrator: Gemini Live
Bidirectional Communication: Supports real-time text, voice, and video calls.

Multimodal Input: Users can show medical images or prescriptions directly via video call or upload them as artifacts.

2. Medical Reasoning: MedGemma Agent
Model: MedGemma (Highly specialized and trained on medical datasets).

Deployment: Hosted on Google Colab using a T4 GPU (~8GB VRAM) to handle heavy model inference.

Artifact Handling: Uses the Model Context Protocol (MCP) to manage and process uploaded reports, images, and X-rays.

3. Verification: A2A Protocol
Agent-to-Agent (A2A): A dedicated Search Agent communicates with the MedGemma agent.

Web Verification: The Search Agent performs web scraping of verified medical sources to cross-check and validate any prescriptions or evaluations generated by the medical agent
